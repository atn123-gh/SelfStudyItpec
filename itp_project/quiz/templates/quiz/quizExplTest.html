Throughput Calculation for Information Processing System

An information processing system consists of a database and web server with the specifications shown in the table below:

Server Type Upper Limit of CPU Utilization Transaction Processing Time required for a CPU (in milliseconds/transaction)
Database 80% 5
Web 90% 4

When the throughput of an entire processing system is determined by the throughput of the server with the lowest throughput, the throughput of the entire processing system in TPS (transactions per second) is calculated.

Calculations:

Database Server:

Transactions per second \(= \frac{1000 \, \text{ms}}{5 \, \text{ms/transaction}} = 200 \, \text{TPS}\)

Throughput \(= \text{Transactions per second} \times \text{Upper limit of CPU utilization} = 200 \times 0.80 = 160\)

Web Server:

Transactions per second \(= \frac{1000 \, \text{ms}}{4 \, \text{ms/transaction}} = 250 \, \text{TPS}\)

Throughput \(= \text{Transactions per second} \times \text{Upper limit of CPU utilization} = 250 \times 0.90 = 225\)

The throughput of the entire processing system is determined by the server with the lower throughput, which is the database server with a throughput of 160 transactions per second (TPS).

Therefore, the throughput of the entire processing system is 160 transactions per second (TPS).
